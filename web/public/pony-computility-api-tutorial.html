Pony Computility 使用文档用户版

面向所有注册用户 · 最后更新 2026-08-06

Pony Computility 是一站式 AI 模型中转站，把 GPT、Claude、Gemini、GLM 等主流大模型聚合到一个兼容 OpenAI 标准的接口下。你只需一个令牌（API Key），就能在任意支持 OpenAI 格式的工具里调用全部模型，按量计费、即充即用。

② 充值
为账户充值额度（按量计费）

1. 注册与登录

打开 pony-token.kai.com，点击右上角「注册」。

  • 支持邮箱 / GitHub / 其他第三方登录。
  • 注册即用，无需审批，没有任何使用门槛。
  • 登录后进入「控制台」即可管理令牌、查看用量与账单。

2. 充值额度

新账户有少量体验额度。正式使用前请在「控制台 → 充值」按需充值。

  • 额度以「$」为单位，1$ = 500000 Token 配额（按模型倍率折算）。
  • 支持支付宝 / 微信 / USDT 等多种方式，到账后实时可用。
  • 所有调用按模型官方价格 × 倍率计费，余额不足时自动停止，不会超额扣费。

3. 创建 API 令牌

进入「控制台 → 令牌」，点击「添加令牌」。

  • 令牌格式为 sk-xxxxxxxx，请妥善保管，切勿泄露。
  • 可设置名称、有效期、可用模型与额度上限，方便分项目隔离。
  • 建议为每个客户端 / 项目单独创建一个令牌，便于用量追踪与随时重置。

4. 快速接入

任意支持 OpenAI 格式的工具，填入以下三项即可接入：

配置项填写内容
API 地址 / Base URLhttps://pony-token.kai.com/v1
API Key / 密钥你创建的 sk-... 令牌
模型 / Model下方「可用模型」中的名称，如 gpt-5.5、claude-opus、glm-4.6

提示：选择「OpenAI 兼容 / Custom OpenAI」类型，不要选官方登录，模型名保持原样不要改。

5. 客户端接入示例

Cherry Studio / ChatBox / NextChat

这类桌面 & 网页客户端接入方式相同：

  • 设置 → 模型服务 → 添加「自定义 / OpenAI 兼容」服务商。
  • API 地址填 https://pony-token.kai.com/v1，密钥填 sk-...。
  • 手动添加或刷新模型列表，选一个模型即可开始对话。

Cursor / VS Code (Continue 等)

  • Cursor：Settings → Models → Override OpenAI Base URL，填入 https://pony-token.kai.com/v1，并填入令牌。
  • VS Code Continue：在 config 里配置 openai 兼容 provider，baseURL 与 apiKey 同上。
  • 模型名要和后台一致，不要带官方后缀。

Python / Node SDK

直接复用官方 OpenAI SDK，只改 base_url 和 api_key：

from openai import OpenAI

client = OpenAI(
    base_url="https://pony-token.kai.com/v1",
    api_key="sk-你的令牌",
)

resp = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)

7. 计费说明

  • 按量计费：每次调用按消耗 Token 数 × 模型倍率扣减额度，用多少扣多少。
  • 价格透明：各模型倍率在「模型广场」公开标示，无隐藏加价。
  • 自动停止：余额耗尽时请求自动拒绝，不会产生欠费。
  • 用量可查：控制台「日志」实时记录每次调用的模型、Token 数与扣费。

8. 调用示例

检查可用模型：

curl https://pony-token.kai.com/v1/models   -H "Authorization: Bearer sk-你的令牌"

发起一次对话：

curl https://pony-token.kai.com/v1/chat/completions   -H "Authorization: Bearer sk-你的令牌"   -H "Content-Type: application/json"   -d '{
    "model": "glm-4.6",
    "messages": [
      {"role": "user", "content": "你好"}
    ]
  }'

9. 常见问题

  • 报 401 / invalid_api_key？ 令牌填错或已失效，去控制台重新复制，注意不要带空格。
  • 报 model not found？ 模型名拼写不对，或该模型未对你开放，请对照「模型广场」。
  • 报 insufficient_quota？ 额度不足，去「充值」加额度即可恢复。
  • 能在手机上用吗？ 可以，任何兼容 OpenAI 的 App 填入地址与令牌即可。
  • 令牌泄露了怎么办？ 立即在「令牌」页删除 / 重置该令牌，再生成新的。
